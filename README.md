# MemorySeller

## 프로젝트 소개

MemorySeller는 어린 시절 즐겼던 게임들을 회고하며 소개하는 웹사이트입니다. 프로젝트 이름은 "추억팔이" 라는 단어에서 유래했으며, 과거의 추억을 되새기는 의미를 담고 있습니다.

본 프로젝트는 HTML과 CSS를 활용하여 게임 플랫폼별로 분류된 게임 정보를 제공합니다.

## 프로젝트 구조

```
MemorySeller/
├── home.html              # 메인 페이지
├── homestyles.css         # 메인 페이지 스타일시트
├── PC/                    # PC 게임
│   ├── 롤/
│   │   ├── 롤page.html
│   │   └── styles.css
│   └── 발로란트/
│       ├── 발로란트page.html
│       └── styles.css
├── Mobile/                # 모바일 게임
│   ├── 마인크래프트/
│   │   ├── 마인크래프트page.html
│   │   └── styles.css
│   └── 쿠키런/
│       ├── 쿠키런page.html
│       └── styles.css
└── Nintendo/              # 닌텐도 게임
    ├── 포켓몬/
    │   ├── 포켓몬page.html
    │   └── styles.css
    └── 마리오/
        ├── 마리오page.html
        └── styles.css
```

## 주요 기능

### 플랫폼별 게임 분류

게임을 플랫폼에 따라 세 가지 카테고리로 구분하여 제공합니다:

- **PC**: 리그오브레전드, 발로란트
- **Mobile**: 마인크래프트, 쿠키런
- **Nintendo**: 포켓몬, 마리오

### 게임별 상세 페이지

각 게임마다 독립적인 페이지를 통해 게임의 특징, 요소, 캐릭터 등 상세 정보를 제공합니다.

## 포함된 게임

### PC 게임

#### 리그오브레전드
- 포지션별 특징 소개 (탑, 정글, 미드, 원딜, 서포터)
- 기타 게임 요소

#### 발로란트
- 에이전트 역할별 분류 (척후대, 타격대, 전략가, 감시자)
- 무기 시스템 (소총, 저격소총, 산탄총, 기관단총, 중기관총)
- 장비 및 맵 정보

### 모바일 게임

#### 마인크래프트
- 게임 요소 및 콘텐츠 소개
- 이미지 자료 포함

#### 쿠키런
- 게임 특징 소개

### 닌텐도 게임

#### 포켓몬
- 포켓몬 시리즈 소개

#### 마리오
- 마리오 시리즈 소개
- 관련 이미지 자료


## 디자인 컨셉

- **색상**: 인기 게임인 "리그오브레전드" 웹페이지를 참고하여 해당 웹페이지에서 주로 사용하는 색으로 구성
- **폰트**: 게임의 정보를 제공하는 문서 형식이기 때문에 가독성이 높은 글꼴을 사용
- **레이아웃**: 
  - 읽기 편한 레이아웃
  - 모바일/태블릿에서도 깨지지 않는 반응형 구성

## 기술 스택

- **HTML5**: 웹 페이지 구조
- **CSS3**: 스타일링 및 레이아웃

## 프로젝트 특징

- 직관적인 카테고리 분류로 쉬운 탐색
- 각 게임별 독립적인 스타일시트를 통한 개성있는 디자인
- 이미지를 활용한 시각적 콘텐츠 제공
- 반응형 레이아웃 구현
